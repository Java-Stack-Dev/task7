# Task 7 – Basic Sales Summary using SQLite and Python

## Objective
Use SQL queries inside Python to get total quantity and revenue from sales, and visualize the result.

## Tools Used
- Python
- SQLite3
- Pandas
- Matplotlib
- Juypter notebook

## Steps Performed
1. Created a SQLite database with a sales table and inserted sample data.
2. Queried the total quantity and revenue per product using SQL in Python.
3. Loaded data into a Pandas DataFrame.
4. Displayed the summary using `print()`.
5. Plotted a simple bar chart of revenue using Matplotlib.

## Output
- `sales_chart.png`: Bar chart showing revenue by product.
